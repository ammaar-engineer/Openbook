# Definisi openbook

Openbook adalah platform opensource yang digunakan untuk membantu para pengguna untuk belajar. Target pengguna nya adalah para murid dengan gaya pembelajaran AI driven ataupun murid yang memiliki AI local atau langganan AI untuk menggunakan platform tersebut. Karena sistem nya adalah BYOK (Bring Your Own Key). Target openbook adalah memudahkan pengguna untuk mempelajari berbagai ilmu dan juga manajemen ilmu yang telah dipelajari
# Fitur fitur pada openbook

- Chat dengan AI Agent
- Soal pilihan ganda dan soal essay interaktif
- Markdown editor dengan dibantu oleh AI Agent (Markdown book)/Markdown book + notes
- Notes untuk menyimpan catatan penting
- Sistem AI BYOK dan kemampuan untuk membuat agents
  
# Penjelasan lebih spesifik dari fitur nya

## Chat dengan AI Agent
Pada halaman awal aplikasi akan ada tampilan chat yang dapat digunakan untuk langsung chat dengan AI yang telah disettings sebelum nya. Pada chat AI Agent ini kita bisa mulai bertanya tanya mengenai persoalan yang tidak diketahui. Lalu pada chat AI Agent ini ada kemampuan untuk si AI membuat soal soal latihan

## Soal pilihan ganda dan juga essay interaktif
Ini adalah fitur yang digunakan untuk mengetes kemampuan kita. AI akan membuatkan kita soal latihan untuk kita jawab ketika kita sedang chatting dengan AI Agent nya jika diperlukan. Dan buku buku yang dibuat oleh AI juga akan ada latihan soal nya

## Markdown editor / Markdown book
Fitur buku markdown yang dapat digunakan untuk mencatat hasil belajar dan juga membuatkan paket materi untuk dipelajari kemudian. Ai agent juga memiliki kemampuan untuk membuat markdown book. Selain itu pada aplikasi juga terdapat fitur untuk edit dari markdown book nya. Dalam markdown book juga terdapat fitur notes yang dapat digunakan untuk menyelipkan materi pendek namun penting secara cepat

## Sistem AI BYOK
Ini adalah fitur untuk membawa AI yang telah dibeli atau langganan pengguna menggunakan API key nya sendiri untuk dipasangkan pada openbook. Sehingga inilah yang menjadi esensi dari projek ini yaitu projek opensource
